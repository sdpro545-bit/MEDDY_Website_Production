# MEDDY GLOBAL SOLUTIONS LTD — Image Branding & Compositing Engine

This directory contains the production compositing pipeline used to place official MEDDY GLOBAL SOLUTIONS LTD branding, emblems, uniform patches, and industrial placards onto corporate photography with mathematical perspective, cylindrical mapping, and physical lighting integration.

## Files Structure

- `engine.js`: Core Node.js / Sharp image processing engine. Performs perspective warping, cylindrical surface projection, multi-layer blending, luminance modulation, and grain matching.
- `placements/`: JSON definitions for every image specifying exact coordinate geometry, scale, rotation, surface curvature, and typography parameters.
- `README.md`: System documentation and execution guidelines.

## Methodological Rules

1. **Vector Typography:** All text is typeset using the official `Manrope` font with exact spelling `MEDDY GLOBAL SOLUTIONS LTD`.
2. **Official Vector Emblems:** Logos are loaded from `/public/brand/logo.png` (dark MG on light) and `/public/brand/logo-footer.png` (light MG on dark).
3. **No Image Model Hallucination:** Logos and text are never generated by diffusion models; they are composited with sub-pixel interpolation in code.
4. **Physical Texture Integration:** Placements use luminance blending to capture real folds, shadows, highlights, and fabric texture.
